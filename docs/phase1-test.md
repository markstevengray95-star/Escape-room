# Phase 1 acceptance checks

All checks below are pending execution in Unreal Editor.

- Development Editor build succeeds; no missing modules or assets.
- Play starts in the lab, player stands on floor, cannot pass through walls or locked door.
- WASD/arrows and mouse camera work; jump lands correctly.
- Interactions only occur while looking at an object within 260 cm; walls occlude targets.
- Locked door denies progress before clue and breaker are completed.
- Open drawer, collect note, confirm inventory changes and note cannot be collected twice.
- Activate breaker; power changes to online. Unlock door; it moves out of the way.
- Walk through doorway and interact with exit; completion message appears.
- Restart Play; room and inventory reset.
- Check lighting, frame rate, UI scaling and potential clipping on a typical school laptop.

Deferred: touch/third-person controls, persistent inventory, science puzzles, multiplayer, production assets, packaging and streaming.
